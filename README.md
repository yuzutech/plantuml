# 🌱 Fork of PlantUML

This fork of [PlantUML](https://github.com/plantuml/plantuml) is no longer maintained.
 
## Why
 
The purpose of this repository was to build native PlantUML binary images optimized for [Kroki](https://kroki.io).
As of **PlantUML 1.2026.5**, the official PlantUML project now ships complete binary images directly. This fork is therefore no longer needed.
 
## Migration
 
Use the official PlantUML releases going forward:
 
- **Releases:** https://github.com/plantuml/plantuml/releases
- **Download:** https://plantuml.com/download
---
 
*This repository is kept for historical reference. Issues and pull requests are disabled.*
